# Minimal Next.js Starter

A clean, minimal Next.js starter template with Tailwind CSS.

## Features

- Next.js 15 App Router
- Tailwind CSS v4
- TypeScript
- Optimized for Vercel deployment

## Getting Started

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).
